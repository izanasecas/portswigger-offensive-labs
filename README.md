# PortSwigger Offensive Labs

Este repositorio contiene **scripts y pruebas de concepto (PoCs)** desarrolladas para laboratorios específicos de la **PortSwigger Web Security Academy**, con un enfoque **ofensivo y realista**.

El objetivo no es resolver el laboratorio de la forma más simple, sino **demostrar impacto real**, replicando técnicas que podrían aparecer en entornos de producción.

---

## 🎯 Enfoque

- Explotación manual de vulnerabilidades web
- Desarrollo de PoCs reproducibles
- Bypasses de filtros y validaciones
- Análisis del impacto desde el punto de vista del atacante
- Pensado para entornos reales, no solo académicos

---

## 🧠 Vulnerabilidades tratadas

Según el laboratorio, los scripts pueden cubrir:

- Cross-Site Scripting (XSS)
- Bypasses de filtros
- Lógica de negocio vulnerable
- Validaciones inseguras del lado cliente/servidor
- Manipulación de parámetros
- Otras vulnerabilidades del OWASP Top 10
